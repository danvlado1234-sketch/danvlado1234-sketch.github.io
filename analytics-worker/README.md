# מערכת סטטיסטיקות — שיעורי הרב (`shiurim-analytics`)

מערכת אנליטיקה מלאה ומותאמת אישית לאתר **שיעורי הרה"ג רבי יצחק ולדומירסקי שליט"א**, הבנויה על **Cloudflare Workers + D1 (SQLite)**.

---

## מה המערכת מודדת ומציגה?

1. **בזמן אמת (Live):**
   * כמה גולשים נמצאים באתר ברגע זה, מאיזה מכשיר ועיר, ובאיזה עמוד הם צופים.
   * כמה מאזינים בפועל לשיעור כרגע, לאיזה שיעור, ובאיזה אחוז מהשיעור הם אוחזים.
   * כמה מבקרים ייחודיים היו ב-30 הדקות האחרונות.
2. **מדדי על (KPIs) עם השוואה אוטומטית לתקופה הקודמת:**
   * מבקרים ייחודיים, מבקרים חדשים מול חוזרים, כניסות (ביקורים), משך ביקור ממוצע, זמן פעיל מול המסך, השמעות שיעורים, שעות האזנה בפועל (ללא דילוגים), מאזינים ייחודיים, שיעורים שהושלמו (הגיעו ל-90%+), צפיות בדפים, אחוז נטישה, הורדות, פתיחת סיכומי PDF, שיתופים והתקנות אפליקציה (PWA).
3. **זמני התחברות והאזנה (שעון ישראל):**
   * מפת חום (Heatmap) של ימים בשבוע × 24 שעות ביממה — גם לזמני כניסה לאתר וגם לזמני האזנה בפועל.
   * פילוח שעות שיא, ימי שיא, והתפלגות אורך הביקורים (מפחות מ-10 שניות ועד מעל שעה).
4. **שיעורים והאזנות:**
   * טבלה מלאה וניתנת למיון של כל השיעורים שהושמעו: כמות השמעות, מאזינים ייחודיים, זמן האזנה כולל, ממוצע הגעה בשיעור (Reach %), אחוז השלמה, הורדות, פתיחת סיכום PDF ושיתופים.
   * פילוח לפי סדרה (מסכת / פרשה / מועד), מהירויות השמעה (`1×`, `1.25×`, `1.5×` וכו'), ואיך הופעל השיעור (לחיצה ישירה, מתוך התור, או המשך אוטומטי).
5. **קהל, מכשירים ומיקום:**
   * תדירות ביקורים (כמה פעמים כל מבקר נכנס וכמה ימים שונים), אפליקציה מותקנת מול דפדפן, סוג מכשיר (טלפון / טאבלט / מחשב), מערכת הפעלה, דפדפן, מדינות וערים, וטבלת "המאזינים הקבועים".
6. **מקורות תנועה, דפים וחיפושים:**
   * מאיפה הגיעו (ווטסאפ, גוגל, ג'ימייל, כניסה ישירה, תמיכה ב-`utm_source` ו-`utm_campaign`).
   * דפי כניסה ראשונים, הדפים הנצפים ביותר, ו**מה חיפשו בתיבת החיפוש** (כולל כמה תוצאות קיבלו — כדי לזהות מה אנשים מחפשים באתר).
7. **יומן ביקורים מלא ומסלול מבקר (User Journey):**
   * לחיצה על כל ביקור או מבקר פותחת ציר זמן מדויק (שעה:דקה:שנייה) של כל פעולה שעשה באתר וכל שיעור ששמע.
8. **ייצוא לאקסל (CSV):**
   * ייצוא מלא של טבלאות הביקורים, ההאזנות, האירועים והמבקרים לקובץ CSV בעברית (מותאם ל-Excel ול-Google Sheets).

## הפעלה ב-4 פקודות (דרך המחשב שלך)

בתיקייה `analytics-worker` נמצא כל קוד השרת ומסד הנתונים. כדי להעלות אותו לחשבון ה-Cloudflare שלך:

### 1. יצירת מסד הנתונים (D1)
פתח טרמינל בתיקיית `analytics-worker` והרץ:
```bash
npx wrangler d1 create shiurim-analytics
```
בסיום הפקודה יודפס `database_id`. העתק אותו והדבק אותו בקובץ `wrangler.toml` במקום `REPLACE_WITH_DATABASE_ID`.

### 2. הקמת הטבלאות במסד הנתונים
```bash
npx wrangler d1 execute shiurim-analytics --remote --file=schema.sql
```

### 3. הגדרת סיסמה ללוח הבקרה
```bash
npx wrangler secret put DASHBOARD_PASSWORD
```
(הקלד את הסיסמה שתרצה לכניסה לדשבורד הסטטיסטיקות).

### 4. פרסום השרת לאוויר
```bash
npx wrangler deploy
```

זהו! הכתובת של לוח הבקרה שלך תהיה:
`https://shiurim-analytics.danvlado.workers.dev`

*(האתר עצמו כבר מוגדר בקובץ `community-config.js` לשלוח נתונים לכתובת הזו אוטומטית).*
